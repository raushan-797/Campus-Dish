# Campus Dish

## Project Description
Campus Dish is a responsive restaurant website designed for college students. It showcases food menus, special offers, a food gallery, and contact information. The website represents a restaurant during the day and a cloud kitchen at night.

## Pages
- **Home:** Introduction, food highlights, pricing and testimonials.
- **Menu:** Food items and menu cards.
- **Offers:** Special offers and food combos.
- **Gallery:** Food and restaurant images.
- **Contact & Location:** Contact form, business details and map.

## Technologies Used
- HTML5
- Tailwind CSS
- Responsive Web Design
- Custom CSS (where required)

## Project Structure
- `index.html` — Home page
- `menu.html` — Menu page
- `offers.html` — Offers page
- `gallery.html` — Gallery page
- `contact.html` — Contact and location page
- `Images/` — Website images
